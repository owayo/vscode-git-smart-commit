# 2026-11-12 定期点検

SCMで選んだリポジトリの誤認と、署名表示によるコミットハッシュの破損を修正した。回帰テスト12件を追加し、全338件が成功した。

## 修正の根拠

SCMメニューから渡される `SourceControl.rootUri` を全5コマンドが捨て、先頭のワークスペースで実行していた。別のリポジトリの変更をステージ・コミットするため、対象URIを共通のルート解決まで渡すよう修正した。明示対象が無効なら停止し、他のリポジトリへ切り替えない。ワークスペース未指定でもSCMの対象は扱う。修正前に7ケースの失敗、修正後に成功を確認した。

`log.showSignature=true` の署名付き履歴では、Gitが検証結果をstdoutに出し、ハッシュ欄へ混入していた。実GitとSSH署名を持つコミットで再現し、回帰テストの失敗を確認した。`--no-show-signature` を指定して混入を防ぐ。テストは秘密鍵や外部の署名検証コマンドを必要としない。

リリース処理はビルド・VSIX作成をタグ公開前へ移した。失敗したビルドのタグだけが公開される順序を修正した。未使用の旧成果物 `out/` は版管理から外し、実装と食い違う終了処理のコメントも修正した。ASTで581コメントを確認し、英語だけの残存はAPI定数名と区切りだった。

## 依存更新と制約

開発環境をNode 26.13.1 / pnpm 12.20.0へ更新した。開発依存はBiome 2.6.7、Vitest / coverage-v8 5.1.0、vsce 4.1.0、ovsx 1.4.0、Node型26.6.6に揃えた。mise・packageManager・CIの指定を揃えた。[pnpm 12移行資料](https://pnpm.io/migration-v11)と[Node 26の変更点](https://nodejs.org/en/blog/release/v26.0.0)を照合した。

API型はローカルでインストール検証できるVS Code 1.144.0に揃え、1.146.0は保留した。Biomeのschemaを更新し、生成lockfileを整形対象から除外した。picomatchのoverride先は4.0.7へ更新し、peer依存の警告も解消した。

指定されたdepupの初回実行は、既存lockfileのセキュリティ修正版が公開後14日を満たさず停止した。今回だけ `--no-age` で最新候補を取得し、OSV検査は維持した。pnpm自身の公開後1日の既定条件ではBiomeが対象外になるため、depupが生成した版指定の除外を記録した。グローバル設定は変更していない。

`--refresh-lock` はpnpm 12へ未対応の引数を渡して失敗したため、[depup #142](https://github.com/owayo/depup/issues/142)へ報告した。通常のdepup更新後にlockfileを再生成し、frozen installも成功した。

## 構造・性能・検証

Claude Opusと全実装を確認した。既存のキャンセル状態機械は役割が分かれ、回帰テストもあるため分割しなかった。PATH探索のキャッシュは環境変更の反映を損なうため追加しない。同時実行の抑制とGitの非同期化は今回の確定修正に含めない。

既存の履歴判定を同じ入力で再計測した。Darwin / arm64、2.54.0 (Apple Git-157)、3回ウォームアップ後に旧・新を交互に各7回実行した。時間の中央値は次のとおり。今回、新たな性能変更は加えていない。

| 履歴件数 | 全件走査 (ms) | 1件限定 (ms) |
| -------- | ------------: | -----------: |
| 0        |         23.02 |        20.54 |
| 100      |         24.39 |        22.03 |
| 50,000   |        198.65 |        21.33 |

5万件のCPU時間は188.84→13.64ms、最大RSSは20,336→6,496KiB。既存の1件限定走査が有効と確認し、追加の最適化は見送った。[全測定値](history-probe-2026-11-12.json)は `python3 scripts/benchmark-history-probe.py --git /usr/bin/git --runs 7` で再計測できる。

338テスト、型チェック、Lint、VSIX作成が成功した。v8 coverageはStatements 99.13% / Branches 94.57% / Functions 100%。依存監査は0件で、peer依存警告もなかった。GitHub Actionsはactionlint（ShellCheckを含む）も成功した。Claude Opusによる差分の再レビューで追加の確定不具合はなかった。Windows実機とMarketplace / Open VSXへの公開は未実施。
